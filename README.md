## 📂 Featured Project
### 🎤 [Top-Grossing Concert Tours Analysis](https://github.com/rawan-and-pandas/concert-tours-analysis)
Data cleaning and EDA of the 20 highest-grossing concert tours.
- Cleaned messy data (footnote markers, currency symbols, year ranges)
- Handled missing values without inventing data
- Found that revenue is driven by per-show earnings, not the number of shows
- Showed how inflation adjustment lifts older tours by up to **+49.8%**
